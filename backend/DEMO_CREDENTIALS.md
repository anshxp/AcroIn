## Functional demo data

The seed now creates one linked record for **every demo student** in each of these collections:

- Projects
- Certificates
- Competitions
- Internships
- Student-to-faculty chats

Each seeded student chat contains an initial faculty message, so the chat UI has real data immediately after seeding.

## Run the seed

From the `backend` directory:

```powershell
npm run seed:demo
```

or:

```powershell
node scripts/seed-complete-demo.js
```

The script prints the final counts so you can verify that MongoDB actually received the records.

Optional development password override:

```powershell
$env:DEMO_SEED_PASSWORD='YourDevelopmentPassword123!'
npm run seed:demo
```

Do not commit production credentials to the repository.
