# AcroIn Development Demo Credentials

Generated by `scripts/seed-complete-demo.js`.

## Dataset

- 120 students: 10 in each of the 12 supported departments.
- 60 faculty: 5 in each department.
- 1 departmental administrator: the first CSE faculty account.
- Existing records are not deleted by the seed script; matching demo accounts are updated/upserted.

## Common password

All accounts created by the complete demo seed use:

`AcroIn@2026`

This is a development/demo password only. Do not use it for production accounts.

## Student accounts

Student email pattern:

`demo.student.<department-lowercase>.<01-10>@acropolis.in`

Examples:

- `demo.student.cse.01@acropolis.in`
- `demo.student.aiml.01@acropolis.in`
- `demo.student.ds.01@acropolis.in`
- `demo.student.csit.01@acropolis.in`
- `demo.student.cyber.01@acropolis.in`
- `demo.student.ece.01@acropolis.in`
- `demo.student.eee.01@acropolis.in`
- `demo.student.vlsi.01@acropolis.in`
- `demo.student.me.01@acropolis.in`
- `demo.student.ce.01@acropolis.in`
- `demo.student.it.01@acropolis.in`
- `demo.student.il.01@acropolis.in`

Each department has accounts `.01` through `.10`.

## Faculty accounts

Faculty email pattern:

`demo.faculty.<department-lowercase>.<1-5>@acropolis.in`

Each department has accounts `.1` through `.5`.

## Departmental administrator

The single departmental administrator is the CSE faculty account:

`demo.faculty.cse.1@acropolis.in`

Password:

`AcroIn@2026`

Its database role is `faculty + dept_admin`; it is not a global `admin` account.

## Seed command

From `backend`:

```powershell
node scripts/seed-complete-demo.js
```

Optional password override:

```powershell
$env:DEMO_SEED_PASSWORD='YourDevelopmentPassword123!'
node scripts/seed-complete-demo.js
```

Do not commit a production password or production credentials to the repository.
